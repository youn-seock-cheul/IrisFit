## 1. 승인된 범위 결정

사용자가 2026-11-15에 베타 MVP 기본 범위를 다음과 같이 선택했다.

**포함 후보:** 홈, 선택적 사용 관련 지표(측정 방식 미결), 30초 휴식, 눈 운동, 기기 내 로컬 완료 기록  
**베타에서 숨김:** 실제 동기화가 없는 커뮤니티/릴레이, 검토 중인 AI Coach, 미구현 PRO/유료 기능

이는 제품 범위 선택이다. 아직 상세 완료 기준의 최종 승인, 코드 수정 승인, Release Hold 해제 또는 배포 승인은 아니다. 점수·알림·기록 보존/삭제 세부정책은 아직 확정하지 않았다.

## 3. 이번 기본설계에 포함하지 않는 항목

- 실시간 커뮤니티/릴레이/글로벌 참가자 동기화
- AI 질문 입력·응답 생성·모델 다운로드/활성화
- PRO 결제/구독 및 유료 혜택
- 카메라·오버레이 기반 눈 추적/눈 상태 분석 (제품 범위 제외 유지; 저전력 실제 시청시간 가능성 조사만 별도 진행)
- 서버 계정/백업/클라우드 기록 동기화
- 배터리 최적화 제외 요청, 알림 기능의 베타 제공 여부

이 항목을 제외하는 것은 기존 저장 데이터나 코드를 임의 삭제해도 된다는 뜻이 아니다. UI 범위와 기존 로컬 데이터의 처리·삭제 여부는 별도 승인 및 영향 분석을 따른다.

## 4. 기본설계 확정 전 결정

1. **IrisFit Battery:** 앱 브랜드/기능 명칭과 숫자·그래픽 병행 의도는 선택되었다. 단, 사용자는 일반적인 전체 앱 전경시간이나 화면 켜짐 시간이 아니라 실제 폰을 손에 들고 보는 시간을 원한다. 기존 사용량 합산은 이 목표를 만족하지 않는다. 저전력 상태에서 실제 시청시간을 추정할 수 있는지 먼저 조사하고, 배터리 영향/정확도 증거와 PM 승인 전까지 지표 정의, 사용시간 산식, 권한 처리 및 개발을 확정하지 않는다. 예비 근거는 `IrisFit_PM_Actual_Viewing_Time_Low_Power_Feasibility_2026-11-15.md`에 기록한다.
2. **눈 운동 범위:** Eye Gym과 Smooth Pursuit를 모두 포함하고 한 번에 한 모드만 동작하도록 한다. 각 모드의 완료 판정 기준은 확정한다.
3. **완료 기록:** 현재 100건 제한을 유지할지, 삭제 시 프로필·목표·응원 설정도 포함할지 정한다.
4. **알림/배터리 최적화:** 베타 포함 여부를 별도 정하고, 포함하는 경우 권한 요청과 Play 정책 근거를 승인한다.
5. **세션 중단:** 앱 백그라운드/프로세스 종료 시 일시정지·폐기·복구 중 기대 동작을 확정한다.

## 5. QA 협의 요청

QA는 각 후보 요구사항의 모호성, 거부/오류/날짜 경계, 저장 중복 및 미측정 표시를 검토하고 테스트 가능한 완료 기준을 제안한다. QA 협의가 끝나도 제품 의미·우선순위·출시 범위는 PM이 승인하기 전까지 확정되지 않는다. QA 역할은 동일 AI의 별도 단계이며, 실기기 검증과 사람의 독립 승인을 대체하지 않는다.
