### 📋 [개발 지시서] (To. 시니어 Android 개발자)

* **작업 목표 (Why):**
  - IrisFit 베타 MVP 버전을 출시하기 위해 핵심 기능(오늘의 화면 사용 시간 측정 및 IrisFit Battery 표시, 30초 휴식, 눈 운동 2종, 로컬 이력 저장)을 안정화하고, 미구현 기능(커뮤니티/릴레이, AI Coach, PRO)에 대한 사용자 이탈 및 오류 감지를 방지한다.
  - 배터리 소모 및 Play Store 정책 위험을 최소화하는 저전력 구간 측정(안 A)을 적용하여 사용자에게 신뢰할 수 있는 "눈 에너지" 정보를 제공한다.

* **상세 요구사항 (What):**
  - **기능 1: IrisFit Battery 사용 시간 지표 (안 A 반영)**
    - 오늘 누적 화면 사용 시간(`UsageStatsManager`)을 1분 간격으로 새로고침 및 foreground 복귀 시 갱신한다.
    - 시간/분 형식(예: `2시간 15분`) 및 이에 상응하는 보조 배터리 그래픽을 함께 제공한다.
    - 권한 미허용 또는 조회 실패 시 `미측정`으로 명확히 구분하여 표시하고 선택적 Usage Access 권한 안내 다이얼로그/버튼을 제공한다.
  - **기능 2: 미구현/베타 차단 기능 팝업 처리 (안 3 반영)**
    - 커뮤니티/릴레이 카드, AI Coach 대화 진입점, PRO 구독/유료 기능 진입 버튼 클릭 시 기능 화면으로 이동하지 않고 `"베타 준비 중입니다."` 안내 다이얼로그 또는 토스트를 노출한다.
  - **기능 3: 30초 휴식 및 눈 운동 (Eye Gym / Smooth Pursuit) 세션 제어**
    - Eye Gym과 Smooth Pursuit는 동시 실행을 금지하며 한 번에 하나의 운동만 실행 가능하도록 세션을 상호 배타적으로 관리한다.
    - 세션 진행 중 앱이 백그라운드로 전환되거나 프로세스가 이탈할 경우 불완전한 기록 저장을 방지하도록 일시정지 또는 세션 취소 로직을 적용한다.
  - **기능 4: 기기 내 로컬 완료 이력 관리**
    - 휴식 및 운동 완료 시 기기 내 로컬 저장소(Room/SharedPreferences)에 날짜·시간·종류별로 저장을 완료하며 중복 저장을 방지한다.

* **예외 처리 및 엣지 케이스:**
  - **Usage Access 권한 거부:** 권한이 없어도 앱의 기본 기능(30초 휴식, 눈 운동) 사용을 막지 않으며, `미측정` 상태로 표시한다.
  - **백그라운드 전환 및 프로세스 종료:** 운동/휴식 타이머 세션 중 홈 버튼을 누르거나 백그라운드 전환 시 타이머가 정상 일시정지되거나 취소되어 무효 기록이 저장되지 않아야 한다.
  - **화면 회전 및 Recomposition:** 타이머 및 상태 변경 시 상태 호이스팅(State Hoisting)을 통해 화면 회전이나 Recomposition 발생 시 타이머 수치가 초기화되지 않도록 처리한다.

* **Google Play 정책 체크포인트:**
  - Usage Access 권한(`PACKAGE_USAGE_STATS`)은 선택적 런타임 권한이므로 강제하지 않으며, 거부 시에도 사용자 경험을 저해하지 않도록 예외 UI를 반드시 보장한다.
  - 의료 진단이나 치료 효능을 주장하는 문구를 지양하고, 사용 습관 보조 지표임을 명시한다.

* **완료 조건 (Acceptance Criteria):**
  1. 홈 화면에서 오늘 누적 사용 시간이 `X시간 Y분` 형식과 배터리 그래픽으로 정확히 표시되고, 앱 복귀 및 1분마다 갱신된다.
  2. Usage Access 권한이 없을 경우 `미측정` 상태가 표시되고 권한 요청 안내 다이얼로그가 정상 동작한다.
  3. 커뮤니티, AI Coach, PRO 클릭 시 `"베타 준비 중입니다."` 안내 팝업이 뜨고 앱이 크래시되거나 미완료 화면으로 이동하지 않는다.
  4. Eye Gym과 Smooth Pursuit 운동 및 30초 휴식이 정상 동작하며 완료 시 로컬 이력에 정확히 1건 저장된다.
  5. 백그라운드 전환 시 타이머 세션 예외 처리가 정상 동작한다.
