## 시험 조건과 운영 제약

- 최종 release와 동일한 전체 R8 설정의 APK 사본을 기존 개발용 인증서로 서명해 시험한다. 이것은 업로드 키/Play 서명 승인이 아니다.
- 자연 알림 시험 중에는 앱을 재설치·강제 종료하거나 타이머를 덮어쓰지 않는다.
- 후속 시험을 위해 USB 연결 중 화면 유지 설정을 임시 사용한다. 원래 값 0으로 복원 완료. 회전 값도 원래 0/0으로 복원 확인했다. 이 조건에서 절전·배터리 소모 성능을 판정하지 않는다.
- 녹화/소리 수신 여부는 실제 관찰한 경우에만 통과 처리한다. 시스템 음소거 상태를 앱 결함으로 단정하거나 몰래 전체 기기 볼륨을 바꾸지 않는다.
- 공개 방침/지원 정보, 판매 방식/가격/상품, 업로드 서명/Console 신고 및 사전 출시 보고서는 소유자 정보/Console 검증이 별도로 필요하다.
