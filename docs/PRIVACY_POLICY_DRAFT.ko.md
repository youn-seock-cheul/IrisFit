## 보안 및 이용자 통제

앱 전용 저장소를 사용한다. 앱 데이터는 클라우드 백업 및 기기 이전 대상에서 제외하도록 설정했다. 앱 내 “이 기기의 앱 기록 전체 삭제”로 안내 완료 기록·예약·기존 기록을 삭제하고 진행 중 안내를 종료하며 카메라 실험이 실행 중이면 종료한다. OS의 앱 데이터 삭제/앱 제거도 이용할 수 있다.

디지털 결제를 추가할 경우 결제 처리 주체, 구매 토큰 검증·보관, 환불·복원 시 데이터 흐름을 반영해 이 방침과 Data safety를 함께 갱신한다. 현재 앱에 인앱 결제 기능은 구현되어 있지 않다.

## 개발용 카메라 실험 (release 제외)

명시적인 사용자 시작과 카메라/오버레이 권한 선택 후 전면 카메라 프레임을 기기 내 ML Kit 얼굴 분석에 사용한다. 앱이 영상 파일을 저장하거나 자체 서버로 업로드하는 경로는 없다. 얼굴/눈 신호가 불확실하면 감지 불가로 표시하며 졸음으로 판정하지 않는다. 알림 및 앱에서 중지할 수 있고 화면 꺼짐 또는 최대 2분 후 종료한다. 이 설명은 SDK 전체 데이터 처리에 대한 독립 검증을 대체하지 않는다.
