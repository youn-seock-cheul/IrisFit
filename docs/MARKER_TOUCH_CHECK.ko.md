# 마커 옵션 직접 조작과 터치 영역 보완

최종 결과: 관련 UI 1개 24.468초 통과, release 빌드/Lint/설치 성공. 설치 release에서 느린 옵션과 좁은 옵션을 각각 눌러도 준비 화면 유지, 시작 버튼 y1022~1157px 고정, 각 체크 영역 높이135px을 확인했다. 원본 artifact Walkthrough도 최신 요약 저장 성공. 기기 화면 유지/회전 값은 0/0/0 복원 확인. 편안함은 사용자 의견 대기다.

2026-11-01. 설치된 release에서 속도 옵션을 직접 누르는 동안 느린 옵션이 반영된 실행 화면으로 전환되는 것을 관찰했다. 좌표/입력 시점·다른 조작의 영향을 배제하지 못했으므로 체크박스가 원인이라고 확정하지 않는다. 체험은 그만하기로 중단했고 완료 기록은 0회였다.

코드 점검에서 체크박스 자체 클릭을 비활성화하고 부모 행에 toggleable을 적용한 구성에 명시적인 최소 행 높이가 없음을 확인했다. 두 옵션 행과 종료 신호 선택 행에 최소 48dp 높이를 부여했다. 선택 문구 길이에 따른 배치 흔들림을 줄이도록 준비 화면의 속도·범위 요약에도 최소 높이를 확보했다.

기존 마커 실기기 검사에서 각 옵션을 누른 직후 SessionPhase.READY가 유지되는지 검증하도록 보강했고 통과했다. 이후 명시적으로 시작하고 20초 종료·회전/일시정지·기록 미합산까지 확인했다. 이것은 특정 원인을 재현·확정했다는 의미가 아니라 준비 상태 유지 경로의 자동 회귀 증거다.

실제 사용자에게 속도/범위가 편안한지는 아직 미확인이다. 기본값은 바꾸지 않았다. 직접 비교를 위해 앱을 준비 화면에 두고 사용자 의견을 받아야 한다. 이번 UI 보완은 단위 경로 계산을 바꾸지 않았으며 단위 23개를 이번에 재실행했다고 표시하지 않는다. 새 결과는 Walkthrough 최신 항목을 따른다.
