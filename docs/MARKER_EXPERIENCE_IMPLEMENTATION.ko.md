# 앱 내 20초 마커 체험 구현

상태: 구현·짧은 검증 완료. 단위 22개(새 마커 4개 포함), debug UI 3개 통과(61.726초, 마커 24.004초). release AAB·경계·AAB 정렬·Lint·최종 테스트용 release 설치/단독 시작 성공. 실제 사용자 편안함은 미확인. 원래 구상의 작은 체험을 30초 화면 휴식과 구분해 추가했다. 의학적 운동 처방·시선 추적 성공 판정이 아니다.

## 제공 흐름

홈 ‘마커 따라보기 체험 20초’ → 정지 마커/준비 안내 → 시작 → 좌우 이동 → 체험 종료 → 홈/다시 하기.

- 10초에 한 번 부드럽게 좌우 왕복하는 경로를 20초 표시한다.
- 표시 영역 안쪽 28dp 여백을 두고, 아주 좁은 영역에서는 중심/반지름을 영역 크기에 맞춘다.
- 일시정지 시 경과 시간과 마커 위치를 유지한다. 회전 시 같은 세션 유지, 앱 이탈 시 일시정지·복귀 후 수동 재개.
- 시작/재개 시 마커가 보이도록 페이지 스크롤을 상단에 맞춘다.
- 기존 선택형 종료 신호를 사용하며 초기값은 무음이다. 사용자 선택은 준비 화면에서만 변경한다.
- 카메라·다른 앱 위 표시 권한을 추가하거나 기존 debug 실험을 release에 연결하지 않았다.
- 체험 완료를 기존 휴식 완료 횟수에 합산하지 않는다. 화면에 확인 버튼을 제공하지 않고 ViewModel 저장 진입점에서도 마커 저장을 차단한다.
- 기존 20분 예약과 자동 연동하지 않는다.

## 코드와 검증

GuidedSession에 기본 30초와 명시적 20초 길이를 지원한다. 기존 호출은 30초 그대로다. MarkerPath는 단조 경과 시간으로 정규화 위치를 계산하고 Canvas가 실제 크기에 맞춰 그린다. ViewModel이 선택 루틴을 유지하므로 회전으로 루틴이 바뀌지 않는다. 프로세스 종료 후 진행 중 체험은 복원하지 않는다.

검증 결과는 실행 완료 후 Walkthrough 최신 항목에 기록한다. 새 단위 검사 4개는 20초 경계·일시정지/위치 유지·경로 범위/주기·좁은 영역을 실제 대기 없이 확인한다. 새 실기기 검사 1개는 시작 전 마커 표시, 실제 20초 체험, 회전/앱 이탈·수동 재개, 완료 기록 미합산을 확인한다. 기존 안내 UI 검사 2개도 함께 실행한다.

상품 페이지 초안에 새 체험과 측정/기록 범위를 반영했다. 기존 개인정보 처리·백업 제외 설정에서 새로운 개인 데이터는 추가하지 않는다.

## 한계와 다음 우선순위

움직이는 점을 표시한 것과 사용자가 눈으로 실제 따라 한 것은 다르다. 자동 성공 점수·시력/피로도 개선 수치는 제공하지 않는다. 다른 앱 위 오버레이·카메라 보정/정확도는 계속 별도 범위다.

다음은 설치된 앱의 20초 체험에서 속도·움직임 범위·중지 버튼 접근성을 짧게 확인하는 것이다. 사용자 체감이 확인되기 전에 경로/속도 옵션이나 오버레이 권한을 확대하지 않는다. 오래 걸리는 검증은 예상 시간과 목적을 먼저 알려 사용자 판단을 받는다.
