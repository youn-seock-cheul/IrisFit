# 마커 속도·범위 선택 개선

상태: 구현·검증·휴대폰 설치 완료. 단위 23개·실기기 UI 1개(24.391초)·최종 release 빌드/Lint/단독 시작 통과. 사용자 편안함에 대한 답변은 아직 없으므로 기본 속도·범위를 임의로 바꾸는 대신 선택형 축소 옵션을 추가했다.

## 사용자 흐름

준비 화면에서 ‘더 느리게 움직이기’와 ‘더 좁게 움직이기’를 각각 선택한다. 현재 선택은 시작 버튼 위의 요약과 진행 화면에 표시한다. 시작·나중에 버튼은 기존처럼 준비 화면 상단에 유지한다.

| 설정 | 기본 | 선택 시 |
| --- | --- | --- |
| 왕복 주기 | 10초 | 16초 |
| 좌우 이동 폭 | 기존 전체 경로 | 기본 폭의 60%, 중심 유지 |
| 전체 체험 시간 | 20초 | 20초 그대로 |

두 옵션은 함께 사용할 수 있다. 실행·일시정지 중에는 설정을 바꿀 수 없고, 다시 준비 화면에서 변경한다. 값은 같은 ViewModel/앱 프로세스 동안만 유지하고 새 프로세스에서는 두 옵션 모두 해제된 기본값이다. 회전 중 선택은 유지한다. 영구 저장·서버 전송·휴식 완료 기록 필드 추가는 없다.

이 값은 UX 선택안이며 의학적 기준이나 편안함의 보장이 아니다. 실제 사용자에게 편한지는 별도 답변이 필요하다. 불편하면 즉시 종료하는 안내는 유지한다.

## 구현·검증

MarkerPath의 기본 인자를 기존 경로와 같게 유지하고, 주기와 진폭만 옵션으로 축소했다. ViewModel은 마커 준비 상태에서만 변경을 허용한다. 기존 30초 휴식·20분 예약·기록 집계는 수정하지 않았다.

단위 23개 통과. 새 검사에서 느린 주기의 4초 지점/16초 반복, 기본보다 작은 초반 이동량, 좁은 옵션의 정규화 좌표 0.2~0.8 범위를 확인한다. 실제 시간 대기 없이 검사했다.

실기기 UI와 최종 release 결과는 Walkthrough 최신 항목을 따른다. UI는 실제 20초 체험을 이용하되 선택·표시·중단/회전·기록 미합산을 확인하는 것으로, 사용자 편안함 통과를 의미하지 않는다. 장시간 알림·절전 시험은 실행하지 않는다.

## 남은 사항

설치 앱에서 두 옵션을 선택했을 때 움직임이 더 편한지 확인한다. 다른 기기/글꼴/창 크기 전부를 검증한 것은 아니다. 다음 범위 확대나 오버레이·카메라 권한 추가는 이 구현으로 결정하지 않는다.
