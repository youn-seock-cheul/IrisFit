# Play Console 신고 검토 초안 — 제출하지 않음

확인일: 2026-11-01. 현재 화면 휴식 타이머 release의 코드·권한 경계를 바탕으로 작성했다. Console 접근, 실제 신고/저장/승인, 운영자·판매 정보 확정은 수행하지 않았다.

## 신고 시 구분할 사항

Google은 Data safety에서 기기 외 전송을 수집으로 정의하며 SDK의 전송도 포함한다. 로컬 저장 자체와 전송은 구분한다. 수집이 없는 앱도 공개 트랙의 신고와 개인정보처리방침이 필요하다. 앱 내 안내창은 공개 URL의 대체물이 아니다. [Data safety 공식 안내](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en).

건강 앱 신고는 건강 기능이 없는 앱도 작성 대상이다. ‘의료기기가 아님’과 ‘건강 관련 기능이 없음’은 별개의 판단이다. 위 문안은 실제 기능 설명 초안이며 특정 분류의 승인 보장이 아니다. [건강 앱 신고 안내](https://support.google.com/googleplay/android-developer/answer/14738291?hl=en), [건강 앱 분류 설명](https://support.google.com/googleplay/android-developer/answer/13996367?hl=en-en).

구형 AI/DMS/카메라 빌드가 활성 Play 트랙에 남아 있는지는 확인하지 못했다. 있다면 그 버전의 기능/데이터 흐름을 포함해 신고 범위를 재검토한다. 경쟁 앱 설명이나 과거 Walkthrough의 구현 완료 목록을 신고 증거로 사용하지 않는다.
