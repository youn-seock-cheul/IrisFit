# 마커 체험 짧은 화면·조작 점검

2026-11-01. Galaxy S23+의 설치된 full-R8 테스트용 release를 직접 UI 조작해 확인했다. 이번에는 앱 코드 변경·재빌드·장시간 시험을 수행하지 않았다.

## 후속 개선 완료

준비 화면의 시작·나중에 버튼을 제목/핵심 안내/현재 종료 신호 아래로 옮기고 준비 진입 시 스크롤을 상단으로 맞췄다. 관련 실기기 검사 1개가 24.236초에 통과했으며 release 빌드·Lint·설치도 성공했다. 설치 release에서 스크롤 없이 두 버튼이 보이는 것을 직접 확인했다(시작 영역 y853–988px, 화면 높이2340px). 아래 스크롤 필요 관찰은 수정 전 기록이다. 속도·범위의 편안함은 여전히 사용자 응답 전이며 실제 체감으로 확대하지 않는다.

## 직접 관찰한 결과 — 수정 전

- 홈 → 마커 체험 준비 → 스크롤 1회 → 안내 시작 → 실행 화면 → 그만하기 → 중단 화면 순으로 조작했다.
- 실행 화면에서 마커 표시 영역은 [101,521]–[979,1027] px, 그만하기 클릭 영역은 [101,1596]–[347,1731] px였다. 1080×2340 화면에서 두 영역이 함께 보였고 시스템 내비게이션 영역과 겹치지 않았다.
- 스크롤 없이 그만하기를 눌러 ‘안내를 종료했어요. 완료 기록은 남기지 않았습니다.’를 확인했다. 오늘 완료 기록은 0회로 유지됐다.
- 준비 화면에서는 긴 안내와 네 종료 옵션 아래에 시작 버튼이 있어, 최초 화면에서 시작 버튼이 보이지 않았다. 한 번 스크롤한 뒤 누를 수 있었다.
- 점이 준비 화면의 중앙 정지 위치와 실행 중 다른 위치에 표시되는 것은 확인했으나, 속도/범위의 편안함이나 사용자 눈 동작을 측정한 것은 아니다.
- 점검 후 다시 하기를 눌러 준비 화면으로 돌려 두었다. 기기 음량·회전·화면 유지 설정은 변경하지 않았다.

## 남은 확인

사용자에게 속도·범위·버튼 사용감에 대한 짧은 답변을 요청했다. 답변 전에는 ‘편안함 확인’으로 표시하지 않는다. 아직 직접 체험하지 못했다는 응답도 가능하다.

현재 객관적 조작 범위에서 그만하기 접근을 막는 문제는 재현되지 않았다. 준비 화면의 시작 버튼을 찾기 위한 스크롤은 개선 후보다.

## 다음 우선순위

준비 화면에서 주요 시작 동작을 더 쉽게 찾도록 안내/종료 옵션의 배치를 간결하게 하는 것을 우선한다. 속도·범위는 사용자 체감 답변 없이 임의로 변경하지 않는다. 오버레이·카메라 권한 확장은 이 점검으로 결정하지 않는다.
