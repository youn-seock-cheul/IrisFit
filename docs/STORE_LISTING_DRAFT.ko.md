# Google Play 상품 페이지 초안 — 승인/게시 전

## 이름

EyeOverlay

## 짧은 설명

계정 없이 시작하는 30초 화면 휴식 안내와 완료 기록, 선택형 휴식 알림.

## 자세한 설명

화면을 오래 보고 있다면 잠시 눈을 떼고 편안하게 쉬어 보세요.

- 계정이나 카메라 없이 시작하는 30초 화면 휴식 안내
- 별도로 선택하는 20초 마커 따라보기 체험(시선 측정·자동 성공 판정 없음, 휴식 완료 기록 미합산)
- 안내의 일시정지·재개·중도 종료
- 사용자가 확인한 안내 완료 기록과 오늘 횟수(최근 100회 기기 내 보관)
- 별도로 사용할 수 있는 휴식 타이머
- 사용자가 시작한 뒤 약 20분 후 한 번 표시되는 휴식 알림
- 알림 권한을 허용하지 않아도 사용할 수 있는 화면 내 타이머
- 앱 내 타이머 종료와 기기 내 기록 전체 삭제
- Google Play에서 업데이트 확인

안내 시간 종료 후 사용자가 따라 했다고 확인해야 완료로 남습니다. 실제 눈 동작이나 건강 개선을 측정하지 않습니다. 안내는 기본 무음이며 종료 소리·진동을 선택할 수 있습니다. 기기 음량·무음·방해 금지 설정에 따라 신호가 제한될 수 있습니다. 앱 이탈·화면 잠금 시 일시정지됩니다.

절전 상태 등 시스템 상황에 따라 알림이 늦어질 수 있습니다. 정확한 시각 알람이 아니며 자동 반복하지 않습니다. 재부팅 후에는 다시 시작해 주세요. 강제 종료한 앱을 다시 열면 남은 시간의 알림을 복원합니다.

이 앱은 의료기기가 아니며 질환을 진단·치료·완치·예방하지 않습니다. 시력·안구건조·졸음·운전 안전을 측정하지 않습니다. 불편하거나 시야에 변화가 있다면 사용을 중단하고 의료 전문가와 상담하세요. 운전 중에는 앱을 조작하지 마세요.

## 알림 지연 검증 메모 — 게시 문구 작성 시 참고
