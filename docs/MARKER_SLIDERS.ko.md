# 마커 속도·범위 슬라이더

사용자 요청으로 두 체크박스를 Material 3의 5단계 슬라이더로 교체했다. 현재 상태: 구현·단위 24개·debug 실기기 UI 1개 통과. 최종 release 빌드/Lint/설치·단독 시작도 성공했다. UI 검사는 24.669초였고 설치 release 직접 터치로 속도3/5(왕복13초)·범위80% 반영과 준비 유지·시작 버튼 표시도 확인했다.

## 표시와 동작

- 이동 속도: 느리게 → 기본. 왕복 시간은 16 / 14.5 / 13 / 11.5 / 10초. 기본은 10초이며 그보다 빠르게 움직이지 않는다.
- 움직임 범위: 좁게 → 기본 폭. 60 / 70 / 80 / 90 / 100%. 중심을 유지하고 기본보다 넓어지지 않는다.
- 현재 단계·왕복 시간·범위 %를 표시하고, 준비 화면의 정지 마커 아래에 선택한 이동 폭을 선으로 미리 보여 준다.
- ‘기본값으로 초기화’는 두 값을 기본 단계로 되돌린다.
- 두 슬라이더는 준비 상태에서만 조절한다. 시작 버튼은 상단 유지, 체험 시간은 20초, 종료 신호는 기존 선택 사용.
- 같은 ViewModel에서 회전/일시정지 중 값을 유지한다. 영구 저장/서버 전송이나 휴식 완료 횟수 합산은 없다.
- TalkBack 등에서 제어 대상을 구분하도록 각 슬라이더에 이동 속도/움직임 범위 이름을 제공한다. 모든 접근성 설정을 실기기로 검증했다는 뜻은 아니다.

## 검증 범위

단위 검사는 5단계 주기·범위 값, 경로 범위, 잘못된 단계 입력의 제한, 기존 기본 경로/20초 상태를 확인한다. 실기기 검사는 슬라이더 의미 동작으로 최솟값 변경·준비 상태 유지·기본값 복원·중간 단계 선택 후 20초 실행, 회전/일시정지·기록 미합산을 확인했다.

체크박스형 인자에서 단계형 인자로 옮기는 과정에 이전 테스트 호출을 함께 변경했고, 최종 재실행에서 모두 통과했다. 기존 23개 결과를 새로운 24개 결과로 재사용한 것이 아니다.

실제 사용자에게 어떤 조합이 편안한지는 별도 의견이 필요하다. 5단계 값은 UX 선택안이며 의학적 기준/효과 보장이 아니다. 장시간 알림/절전 시험은 이번 범위에 없다.
