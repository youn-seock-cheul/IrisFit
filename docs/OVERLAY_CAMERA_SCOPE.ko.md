# 오버레이·카메라 추가 가치와 다음 구현 범위

2026-11-01. 현재 코드와 제품 흐름에 근거한 설계 검토다. 새 시장 조사·효능 시험·기능 구현은 이번 작업에 포함하지 않는다.

## 후속 구현 갱신

앱 내 20초 마커 체험을 production 소스에 구현했다. 새 경로 단위 검사 4개를 포함한 총 22개, 마커/기존 안내 실기기 UI 3개가 통과했다. 아래 표와 범위는 구현 전 검토 기록이며 최신 결과는 [마커 체험 구현](MARKER_EXPERIENCE_IMPLEMENTATION.ko.md)과 Walkthrough를 따른다.

현재 휴식은 ‘화면에서 시선을 떼기’다. 화면 속 마커를 보는 활동과는 별도 루틴으로 제공해야 한다. 오버레이/카메라가 꼭 필요하다는 결론이나 건강 개선 효과를 이 비교에서 도출하지 않는다.

## 권장하는 다음 작은 구현

**앱 안에서만 실행하는 20초 ‘마커 따라보기’ 체험**을 별도 선택지로 만든다. 이는 원래 구상을 구체적으로 비교하기 위한 UX 프로토타입이며 의학적 운동 처방이 아니다.

- 홈에서 ‘화면에서 쉬기 30초’와 ‘마커 따라보기 체험 20초’를 구분.
- 준비 문구: ‘화면 속 점이 천천히 움직입니다. 편한 범위에서만 따라보세요. 불편하면 바로 종료하세요.’
- 시작 전에는 마커가 정지. 시작 후 좌우 왕복 한 경로만 제공하고 속도/방향 설정은 최초 범위에서 제외.
- 표시 영역 안쪽 여백을 둬 마커가 시스템 바나 버튼을 덮지 않게 배치. 남은 시간·일시정지·계속·그만하기 제공.
- 회전 시 같은 세션 유지. 앱 이탈/잠금 시 일시정지, 복귀 후 수동 재개. 프로세스 종료 후 자동 재개 없음.
- 현재 화면 휴식의 종료 신호를 재사용할지는 구현 시 사용자 선택을 동일하게 제공하되 기본 무음을 유지.
- 종료 후 ‘체험 안내 종료’와 홈/다시 하기를 제공. 카메라를 사용하지 않으므로 눈으로 따라 했는지 자동 확인하지 않음.
- 최초 범위에서는 기존 휴식 완료 기록에 합산하지 않음. 현재 저장소가 screen_rest/30초만 허용하므로 다른 루틴을 같은 기록으로 저장하면 잘못된 집계가 된다. 별도 체험 기록은 필요성이 확인된 뒤 스키마 변경과 함께 설계.
- 기존 20분 알림, 카메라/오버레이 권한을 자동으로 켜지 않음.

## 수용 기준과 짧은 검증

1. 루틴 이름과 안내가 화면 휴식/마커 활동을 구분한다.
2. 마커 좌표는 표시 영역 안에 있고, 일시정지 시 위치·시간이 멈춘다.
3. 중단/회전/홈 복귀로 새 세션·가짜 추적 점수·휴식 완료 기록을 생성하지 않는다.
4. 시간/경로 경계는 가짜 시계 단위 검사로 확인한다. 기기에서는 20초 실행 1회와 중단/복귀를 약 1분에 확인한다.
5. 빠른 움직임·다양한 기기·장시간 평가가 필요해지면 목적·예상 시간을 먼저 설명해 사용자가 진행 여부를 판단하게 한다.

## 이후 오버레이·카메라의 도입 조건

앱 내 체험 후 사용자가 다른 앱 위에서도 같은 활동을 할 필요가 있는지 먼저 확인한다. 필요가 확인되면 수동 시작·즉시 종료·가림 최소화 범위의 debug 오버레이부터 비교한다. 판매 release 경계에서 연구 기능을 일괄 다시 켜지 않는다.

카메라는 얼굴/눈 신호 상태와 ‘마커를 보고 있음’을 구분해야 한다. 중앙 고정 좌표나 기본 능력 점수를 성공/효능으로 표시하지 않는다. 카메라를 다시 제품에 연결하는 단계에서는 CameraX 생명주기·권한·미검출·보정·정확도 검증을 별도 진행한다.

## 이번 완료 보고

- 완료: 네 후보의 추가 가치·현재 한계 비교, 앱 내 20초 마커 체험의 작은 구현 범위·기록 분리·짧은 수용 기준.
- 발견 이슈: 현재 카메라 좌표는 중앙 고정, 현재 기록 스키마는 30초 화면 휴식 전용. 그대로 연결하면 잘못된 성공 판정/집계가 된다.
- 미실행: 코드 변경·빌드·기기 테스트. 이번에는 비교/범위 정의만 수행.
- 다음 우선순위: 위 앱 내 마커 체험 구현. 제품/가격 결정은 지금 요구하지 않는다.
- 종료 신호: 사용자가 ‘확인했습니다’라고 응답한 사실을 기록한다. 소리와 진동 각각의 관측 결과/기기 조건은 제공되지 않아 개별 통과를 단정하지 않는다.
